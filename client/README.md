# Order desk UI

Vite + React + Tailwind client for the order desk agent: the email dashboard, the order detail
view, suggestions and the chat. It talks to the FastAPI server through the `/api` proxy
(`vite.config.ts`). See the README at the repository root for setup and the API.

```bash
yarn install
yarn dev   # http://localhost:5173, with the server running on :8000
```
